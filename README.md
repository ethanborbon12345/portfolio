# Ethan C. Borbon — Student Portfolio

A responsive, single-page portfolio for Ethan C. Borbon, BSIT third-year student at Cebu Eastern College, with a purple creative visual style.

## Included
- Responsive Home, About, Skills, Projects, and Contact sections
- Mobile navigation menu
- Working in-page navigation and back-to-top link
- Email and Facebook links
- Project cards ready for your real projects
- Local profile image placeholder
- No framework or build process required

## Preview locally
1. Extract the ZIP file.
2. Open the `ethan-portfolio` folder.
3. Double-click `index.html` to open it in a browser.
4. For a better development preview, open the folder in VS Code and use the Live Preview or Live Server extension.

## Add your profile photo
1. Copy your photo into the `assets` folder.
2. Rename it `profile.jpg` (or update the image path in `index.html` if using another filename).
3. Refresh the browser. A clear, vertical portrait works best.

## Personalize project cards
Open `index.html` and find the `<!-- PROJECTS -->` section (search for `id="projects"`). Replace each sample title and description with your actual project details. Add project links and screenshots only when you have them. The current cards are placeholders, not claims of completed work.

## Publish using GitHub Pages
1. Sign in at https://github.com and create a **public** repository named `portfolio`.
2. Upload the **contents** of this folder (including `index.html`, `style.css`, `script.js`, and the `assets` folder) to the repository root. Do not upload only the ZIP.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select branch `main` and folder `/(root)`, then save.
6. Wait for publishing, then open the URL shown on the Pages settings screen. It will usually look like `https://YOUR-USERNAME.github.io/portfolio/`.
7. Test the live link in a private/incognito window and on a phone.

## Before submitting
- Replace the profile placeholder with your own photo, if desired.
- Add your real project information and screenshots.
- Check the email and social links.
- Test mobile layout and all navigation links.
- Submit the public website URL, not the GitHub repository URL.

- `script.js` — mobile menu, active navigation, and back-to-top behavior
- `assets/profile.jpg` — add your own profile photo here
